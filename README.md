# OpportunityKit — LogicLooms

A lightweight, responsive prototype for SETU 2026 PS-03. It compares a student profile against a sample internship and explains each requirement as Match, Mismatch, or Missing information.

## Run locally
1. Extract this ZIP.
2. Open `index.html` in Chrome or Edge. No installation or API key is required.
3. Change profile values and click **Check my readiness**.
4. Use **Print / Save report as PDF** to export the report.

## Features
- Student profile inputs and validation
- Sample internship requirements
- Rule-based assessment with explanations
- Distinguishes unknown information from confirmed mismatch
- Suggested next steps
- Responsive layout and print-friendly report

## Scope note
This is a front-end prototype. It uses illustrative sample data and browser-side logic; it does not include a backend, account system, live opportunity feed, or cloud database. Do not describe those as implemented.

## Tech
HTML, CSS, vanilla JavaScript.

## Demo flow
1. Open the page and introduce the purpose.
2. Show the sample profile and sample opportunity.
3. Click Check my readiness and explain the three statuses.
4. Change CGPA, skills, portfolio and availability; rerun the check.
5. Show next steps and print-to-PDF report.
